# Dermalyze - Backend API 🔬

This repository contains the custom backend infrastructure for the **Dermalyze** application, designed for skin lesion screening and diagnosis.

The API was developed in **Python with FastAPI** and orchestrated via **Docker**. It is responsible for securely receiving, storing, and managing clinical information, healthcare professional data (Doctors and Health Agents), and the lesion images captured by the mobile application.

This backend was structured to support the app's *offline-first* architecture, allowing data to be synchronized as soon as the mobile device restores its internet connection.


## ⚙️ Prerequisites

To run this project, you will need to have the following installed on your machine:
* [Docker](https://docs.docker.com/get-docker/)
* [Docker Compose](https://docs.docker.com/compose/install/)


## 🛠️ Configuration

The main configuration resides in the `docker-compose.yml` file. Before starting the server for a production or real testing environment, please pay attention to the following points:

1. **Database Credentials:**
   By default, the passwords are set directly in the `docker-compose.yml` (`rootpassword`, `api_password`). For better security, it is recommended to create a `.env` file in the project root and replace the variables in the Compose file.

2. **Image Storage:**
   The volume mapping is configured to save images in the `./images` folder on your host machine. Make sure Docker has write permissions for this directory.

3. **Access Ports:**
   Ensure that ports `8000` (FastAPI), `3306` (MySQL), and `8080` (phpMyAdmin) are not being used by other services on your computer.


## 🚀 How to Run

With Docker running on your machine, open the terminal in the project root (where the `docker-compose.yml` file is located) and execute the following command:

```bash
docker-compose up --build
```

*Tip: Add the -d flag at the end of the command to run the containers in the background (detached mode).*

During the first execution, the system will download the MySQL and Python images, install the dependencies, and SQLAlchemy will automatically create the users, clinical_info, and images tables in the database.

## 🌐 Accessing the Services
Once the containers are up and running, the following services will be available:

* API Documentation (Swagger UI): http://localhost:8000/docs
    * Interactive interface automatically generated by FastAPI. You can test data submission and image uploads directly from this screen.
* Database Dashboard (phpMyAdmin): http://localhost:8080
    * Server: db
    * User: root
    * Password: rootpassword (or the one you configured)
* API Status: http://localhost:8000/
